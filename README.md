# Webtoon Price Calculator V2

เครื่องคิดเลขราคาตอนการ์ตูน — คำนวณและเปรียบเทียบความคุ้มค่าของแพ็กเกจเติมเงินจากหลายแอปพลิเคชัน

## ✨ ฟีเจอร์

### จากต้นฉบับ (ปรับปรุงใหม่)
- **เลือกแอปพลิเคชัน** — Dropdown เลือกแอป + ตั้งราคาต่อตอน + Presets ลัด
- **เปรียบเทียบโปรโมชัน** — กรอกข้อมูลแพ็กเกจโปรโมชันชั่วคราวเพื่อเทียบกับแพ็กเกจปกติ
- **ตารางสรุปเปรียบเทียบ** — ตาราง Sort/Filter/Budget/Compact + แสดงแพ็กเกจที่คุ้มที่สุด
- **ฐานข้อมูลแพ็กเกจ** — เพิ่ม/แก้ไข/ลบ แพ็กเกจ + Edit mode พร้อม Cancel
- **จัดการแอป** — สร้าง/แก้ไข/ลบ แอป + Presets ราคา
- **Export / Import / Reset** — สำรองข้อมูลเป็น JSON / นำเข้า / โหลดใหม่จากค่าตั้งต้น

### ฟีเจอร์ใหม่
- **📊 กราฟแสดงผลความคุ้มค่า** — Bar chart แสดงราคาต่อตอน (แถบยิ่งสั้น = ยิ่งคุ้ม)
- **⚔️ เปรียบเทียบข้ามแอป** — ดูภาพรวมแพ็กเกจที่ดีที่สุดของทุกแอปในหน้าเดียว
- **🌙☀️ Light / Dark Mode** — สลับธีมได้ จำค่าไว้อัตโนมัติ
- **🎨 UI/UX ปรับปรุงใหม่** — แยกไฟล์เป็นระเบียบ, Responsive ดีขึ้น, Tooltip, Empty state

## 📂 โครงสร้างไฟล์

```
Webtoon/
├── index.html          ← หน้าหลัก (V2) สำหรับ GitHub Pages
├── css/
│   └── style.css       ← สไตล์ (scrollbar, animation, theme toggle, tooltip)
├── js/
│   ├── data.js         ← ข้อมูลแพ็กเกจตั้งต้น (6 แอป)
│   ├── app.js          ← Vue 3 application logic
│   └── chart.js        ← Chart.js wrapper module
├── v1/                 ← เวอร์ชันแรก (Legacy V1)
│   ├── index.html
│   └── data.js
└── README.md           ← ไฟล์นี้
```

## 🚀 วิธีใช้งาน

1. เปิดไฟล์ `index.html` ในเบราว์เซอร์ (ไม่ต้องติดตั้งอะไรเพิ่ม)
2. เลือกแอปพลิเคชันที่ต้องการ
3. ตั้งราคาต่อตอน (หรือใช้ปุ่ม Presets)
4. ดูตารางสรุปเพื่อเปรียบเทียบแพ็กเกจ
5. (ตัวเลือก) กรอกโปรโมชัน / เปิดกราฟ / เทียบข้ามแอป

## 🔧 Tech Stack

- **Vue 3** (CDN) — Reactive UI framework
- **Tailwind CSS** (CDN) — Utility-first CSS
- **Chart.js** (CDN) — กราฟ visualization
- **Sarabun** (Google Fonts) — ฟอนต์ภาษาไทย

## 📌 หมายเหตุ

- ข้อมูลบันทึกใน `localStorage` ด้วย key `webtoonCalcV2`
- ธีม (Light/Dark) บันทึกด้วย key `webtoonCalcV2_theme`
- โปรเจกต์นี้แยกจากต้นฉบับโดยสมบูรณ์ ไม่มีการอ้างอิงไฟล์ข้ามโฟลเดอร์
